# Travaux pratiques Cloud

Emplacement réservé aux futurs TP officiels, séparé des cours et des révisions.

Pour chaque TP, créer un dossier `TP_01_nom_du_sujet/` contenant selon les besoins `sources/`, `code/`, `resultats/` et `rapport/`, avec les instructions de lancement dans son README. Ne pas ajouter de secrets ni d’identifiants cloud.

La préparation VM et load balancing est actuellement dans l’[Atelier du cours](../Cours/Atelier/README.md), rubrique « Préparer les TP » ; elle est proposée pour l’entraînement.
